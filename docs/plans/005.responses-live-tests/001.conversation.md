# Step 001 — Shared live helper and conversation tests on Responses

## Goal

This step adds the shared live-test helper module. It also adds live conversation tests on both Responses classes: multi-turn history, the system instruction followed, non-English streaming, and streamed `generate` on llama-swap. The step is test-only (DEC-005-1).

## Source files

none

## Test files

tests/integrations/live_support.py
tests/integrations/test_responses_conversation.py

## Interface intent

**Library interfaces.** None added or changed. The skeleton records "none: test-only".

**Test-side helper module `tests/integrations/live_support.py`.** The test-coder writes it (DEC-005-2). It imports nothing from other test files and holds:

- **Server, model and key readers** (DEC-005-3):
  - the llama-swap address (variable chain with its default);
  - the llama-swap chat model and the llama-swap embedding model;
  - the OpenAI plain, reasoning and embedding models;
  - the OpenAI key. It returns the key, or skips the calling test when the key chain is empty;
  - the fixed OpenAI address.
- **Responses client builder.**
  - Inputs: a backend token (`openai` / `llamaswap`), a model, and optional overrides for default options, time limit, address and credential.
  - Output: a client built through `get_llm_client` with `protocol` omitted.
  - OpenAI gets the key from the reader unless a credential override is given. A credential override never triggers the skip.
  - llama-swap gets the thinking-off client default unless overridden (DEC-005-4).
- **Piece recorder.** An object usable as `on_delta`. It keeps every piece in order and exposes the list of pieces and their join.
- **Reasoning helpers** (DEC-005-6):
  - a strict well-formed-block check over a text. It passes when there are no markers;
  - answer-text extraction: the text with every reasoning block and marker removed;
  - a no-marker check: neither `<think>` nor `</think>` appears.
- **Secret-free error check.** Inputs: an `LLMError` and a secret. It asserts that the secret appears in none of the error's text, repr, message and description.

**Test file `test_responses_conversation.py`.** Module-local prompts, the history token, and the script-range checks of DEC-005-7.

## Definition of done

1. [test] (live) A client built by the helper with no protocol override is an `OpenAIAPIClient` for `openai` and a `LlamaSwapAPIClient` for `llamaswap`. These are the classes every 005 test targets (US-056.AC-1, DEC-005-3).
2. [test] (live) Multi-turn history, non-streamed, on both backends. The conversation is: user turn, then an assistant turn holding the neutral token, then a user turn asking to repeat it. The reply contains the token, ignoring case. The caller's message list is unchanged after the call (US-006.AC-1, US-006.AC-3, US-057.AC-1, DEC-003-11, DEC-005-6).
3. [test] (live) The same multi-turn history, streamed with a recorder, on both backends. The return contains the token and equals the recorder's join. The recorder's output passes the well-formed-block check (US-008.AC-1, US-057.AC-1, DEC-005-6).
4. [test] (live) `chat` with the uppercase-only system instruction, non-streamed, on both backends. The answer text holds at least one letter, and all its cased letters are uppercase (US-006.AC-2, DEC-arch-3, DEC-005-7).
5. [test] (live) `generate` with the same system instruction, non-streamed, on both backends. The same check applies (US-012.AC-2, DEC-arch-3, DEC-005-7).
6. [test] (live) Streamed `chat` with the multilingual prompt, on both backends:
   - the return equals the recorder's join;
   - the return holds at least one Cyrillic letter and at least one Japanese character;
   - no piece and not the return holds U+FFFD.

   (US-036.AC-1, US-036.AC-3, US-057.AC-1, DEC-005-7)
7. [test] (live) Streamed `generate` on llama-swap with a three-sentence prompt:
   - the recorder gets at least two pieces;
   - the return is non-empty and equals the recorder's join;
   - the recorder's output passes the well-formed-block check.

   (US-013.AC-1, US-013.AC-3, US-057.AC-1, DEC-005-7)
