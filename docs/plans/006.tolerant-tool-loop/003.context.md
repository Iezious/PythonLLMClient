## Time limits today

- `ClientTimeout(total=...)` is built per request in `_request` (~:62, with an unused per-call `timeout` keyword override, DEC-000-16 withdrawn — leave it) and in `_stream_post` (~:132). The session is created without a timeout (~:32).
- DEC-arch-20: add `sock_read=self.read_timeout` next to `total=self.timeout` on the streamed request only. `None` → no per-read limit (aiohttp's default for `sock_read`).
- aiohttp raises its own timeout exception type (a subclass of `asyncio.TimeoutError`) when the per-read limit expires during a read; the existing mapping of timeouts to the `timeout` kind must cover it when it surfaces while the SSE reader consumes the body.
