## Interface intent

- **`LLMClient`** (changed) — generic over one settings-shape type parameter; `default_options` and every operation's `options` use that parameter. Entering the usage scope returns the instance's own type (`Self`); leaving it is fully annotated. Its `chat_with_tools` declaration takes `messages` as a read-only sequence of string-keyed mappings with values of any type (interfaces.md § Exposed: typing contract); no new parameters yet (DEC-006-10). All remaining unannotated functions (e.g. the session helper and the stub methods flagged by mypy) are annotated.
- **`OpenAIAPIClient`, `LlamaSwapAPIClient`, `OpenAIChatCompletionsClient`, `LlamaSwapChatCompletionsClient`** (changed) — each binds the base to the OpenAI settings shape (llama-swap has no shape of its own, DEC-000-18); each `chat_with_tools` takes `messages` as the same read-only sequence of mappings; internal annotations fixed until strict-clean. Copying the caller's messages into the loop's own list keeps the caller's sequence unmodified.
- **`OllamaAPIClient`** (changed, header only) — binds the base to its own settings shape; nothing else (DEC-006-13).
- **`get_llm_client`** (changed) — return type is `LLMClient[Any]`.
- **`llm/trace.py`** — remaining unannotated function annotated; no behaviour change.
- **`pyproject.toml`** — mypy in the `dev` extra and the `[tool.mypy]` table with the Ollama per-module override (DEC-006-1); `uv.lock` refreshed.
