# Step 004 — llama-swap Responses class: settings, request and non-streamed reply

## Goal

`LlamaSwapAPIClient` speaks Responses for non-streamed `chat`, `generate` and `chat_json`, as its own copy of the logic (DEC-arch-2): only the app's settings are sent, translated; no-counterpart settings are dropped with the warning; thinking and an explicit effort reach the engine as the reasoning effort, without a summary; tool chat is refused until feature 004. The credential stays optional; model listing and embeddings stay as they are.

## Source files

llm/llama_swap.py

## Test files

tests/test_llamaswap_responses_request.py

## Interface intent

- **`LlamaSwapAPIClient`** (rewritten for Responses; class docstring states the protocol): constructor unchanged in shape, credential optional (US-005); it additionally creates the per-instance record of settings already warned about (DEC-003-6).
- **Supported-settings and alias tables**: per DEC-003-9.
- **`_merge_options`**: inputs the call's options; output the Responses wire fields (DEC-003-9, DEC-003-10, DEC-003-1, DEC-003-2 — no summary); emits `LLMSettingIgnoredWarning` per DEC-003-6.
- **Response-format translation**, **payload builder** (also used by step 005), **reply extraction**: private helpers with the same responsibilities as in step 002, written in this module (DEC-003-10, DEC-003-11, DEC-003-12).
- **`chat`**: non-streamed path sends through `_request` to `/responses` inside the trace session and returns the extracted text. The streamed path is step 005's.
- **`generate`**: a one-message chat through `chat` (DEC-000-8).
- **`chat_json`**: non-streamed Responses request with the JSON text format (DEC-003-10); parse check unchanged (DEC-000-37).
- **`chat_with_tools`**: same signature; raises `NotImplementedError` per DEC-003-4 before settings are merged or any request is sent.
- **Removed from this module**: the chat-completions-only code (tool loop, `_tools_stream_request` seam, chat-completions streaming call); it lives on in `llm/llama_swap_chat_completions.py`.
- **`list_models`, `get_models`, `embed_batch`**: kept exactly as they are (US-057.AC-2).

## Definition of done

1. [test] A non-streamed `chat` with no settings sends exactly one request, `POST /responses`, whose body has exactly the keys `model`, `input`, `stream` (false), `store` (false) and `include` (`["reasoning.encrypted_content"]`) (DEC-003-11, DEC-arch-7, US-018.AC-1).
2. [test] Each caller message becomes a role/content input item in order; a truthy system instruction is a system-role item at the head; an empty one adds none; the caller's list is unchanged (US-006.AC-2, US-006.AC-3, US-007, DEC-arch-3, DEC-003-11).
3. [test] `generate` sends the system item (when given) and one user item holding the prompt (DEC-000-8, DEC-003-11).
4. [test] The returned text is the concatenation of every output-text part of every message item, in order; reasoning items (including ones with plain reasoning text and empty encrypted content) never appear in it; a reply without message items or text returns empty text (US-006.AC-1, US-028.AC-1, US-009.AC-1, DEC-003-12).
5. [test] A reply with status failed raises `LLMError` carrying the server's error message; status incomplete raises `LLMError` carrying the incomplete reason (DEC-003-12).
6. [test] Temperature, top-p and end-user id set by the app are sent under their names; the output-token cap (`max_tokens` or `context_length`) is sent as `max_output_tokens`; a per-call `None` removes a client default; a per-call value wins; an unknown key is not sent and raises no warning (US-014.AC-2, US-015.AC-1, US-016.AC-2, US-017.AC-1, US-017.AC-2, DEC-003-9).
7. [test] Each of presence penalty, frequency penalty, seed, stop sequences and token bias, set by the app, is absent from the request and the call returns normally (US-061.AC-1, DEC-003-9).
8. [test] Such a setting emits one `LLMSettingIgnoredWarning` naming it on the first call; a second call on the same client emits none for it; another setting emits its own; a second client instance warns again (US-061.AC-2, DEC-arch-6, DEC-003-6).
9. [test] Thinking on sends reasoning effort medium, or the explicit effort when given; no summary is ever sent (US-025.AC-1, US-025.AC-6, DEC-003-2).
10. [test] Thinking off sends reasoning effort none, or the explicit effort when given (US-025.AC-2, US-059.AC-3, DEC-003-1, DEC-003-2).
11. [test] Thinking unset sends no reasoning field; an explicit effort alone is sent as the reasoning effort; neither the thinking switch nor the effort appears as a top-level key in any case (US-018.AC-1, US-025.AC-6, DEC-003-2).
12. [test] A response-format setting is sent as the text format on `chat`: JSON-object as is, a nested JSON-schema format flattened, any other value unchanged (DEC-arch-10, DEC-003-10).
13. [test] `chat_json` sends the JSON-object text format when no response-format setting is set and the translated setting when one is; it sends `stream` false and returns the reply text; with an expected shape, invalid JSON raises `LLMError` and a valid single JSON value is returned unchanged (DEC-001-2, DEC-003-10, DEC-000-37).
14. [test] `chat_with_tools` raises `NotImplementedError` naming `LlamaSwapChatCompletionsClient`; no request is sent and no warning is emitted, even with no-counterpart settings set (DEC-003-4).
15. [test] A non-2xx reply (e.g. a 404 with a JSON error body) raises `LLMError` carrying the request address and the server's reply and not the credential; exactly one request was made, to `/responses`, and none to `/chat/completions` (US-060.AC-1, US-060.AC-3, US-060.AC-4, US-056.AC-4).
16. [test] Built with a credential, requests carry it as the bearer header; built without one, the call works and carries no such header (US-005.AC-1, US-005.AC-2).
17. [test] `list_models`, `get_models` and `embed_batch` send the same requests and return the same results as `LlamaSwapChatCompletionsClient` for the same canned replies, and emit no warning (US-057.AC-2, DEC-003-6).
18. [test] With tracing enabled, a non-streamed `chat` returns the same text and its record shows the request to `/responses` and the returned text (US-049.AC-11, US-050.AC-4).
