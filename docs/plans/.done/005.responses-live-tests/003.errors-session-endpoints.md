# Step 003 — Errors, session reuse and non-chat endpoints on Responses

## Goal

This step adds live tests on the Responses classes for the following:

- a bad OpenAI credential and an unreachable server end with the library's error, without the credential and with the address;
- one client serves concurrent calls and works again after its usage scope closes;
- `embed`, `embed_batch` and `get_models` work on the Responses classes.

The step is test-only (DEC-005-1).

## Source files

none

## Test files

tests/integrations/test_responses_errors.py
tests/integrations/test_responses_session.py

## Interface intent

**Library interfaces.** None added or changed.

**`test_responses_errors.py`.** It uses the helper's builder with credential, address and time-limit overrides, plus the secret-free error check. It holds module-local constants for the dummy key and the closed-port address (DEC-005-8).

**`test_responses_session.py`.** It uses the helper's builder, embedding-model readers and recorder. It holds a module-local cosine-similarity helper (DEC-005-7).

## Definition of done

1. [test] (live) Non-streamed `chat` on OpenAI Responses with the dummy key of DEC-005-8 ends with `LLMError`:
   - its text contains the refusal status `401`;
   - its description is non-empty, carrying the server's reply;
   - the key appears nowhere in the error (secret-free check).

   The test never skips (US-060.AC-1, US-060.AC-4, US-011.AC-1, DEC-000-11, DEC-005-8).
2. [test] (live) The same with streamed `chat` and a recorder. The same assertions apply, and the test never skips (US-060.AC-1, US-060.AC-4, US-011.AC-1, DEC-arch-5, DEC-005-8).
3. [test] (live) Non-streamed `chat` on each Responses class pointed at the closed local port of DEC-005-8 ends with `LLMError` whose text names that address. The OpenAI client gets the dummy key. The test never skips and needs no server (US-011.AC-3, DEC-001-7, DEC-005-8).
4. [test] (live) The same with streamed `chat` on each class (US-011.AC-3, DEC-001-7, DEC-005-8).
5. [test] (live) Concurrent calls, on both backends. One client inside one usage scope runs the four concurrent calls of DEC-005-10:
   - all four return non-empty text;
   - each streamed call's return equals its own recorder's join.

   (US-029.AC-1, DEC-005-10)
6. [test] (live) Reuse after the scope, on both backends. After the scope in DoD-5 closes, the same client object used in a new usage scope returns non-empty text from a non-streamed `chat` (US-004.AC-2, DEC-000-24, DEC-005-10).
7. [test] (live) `embed` on a Responses class built through the factory with the embedding model, on both backends. It returns one non-empty list whose items are all numbers (US-041.AC-1, US-057.AC-2, DEC-005-3).
8. [test] (live) `embed_batch` of three unrelated texts on the same client, on both backends:
   - it returns three vectors of equal non-zero length;
   - each batch vector is most similar to the single vector of the same text.

   (US-042.AC-2, US-042.AC-5, US-057.AC-2, DEC-002-8, DEC-005-7)
9. [test] (live) `get_models` on a Responses class built through the factory, on both backends. It returns a non-empty list, and every entry is a mapping (US-045.AC-1, US-057.AC-2).
