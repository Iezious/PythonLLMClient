## Gotchas

- `aiohttp.ClientResponseError` is a subclass of `aiohttp.ClientError`; the transport mapping must not swallow the status mapping (DoD-5 must keep its exact message).
- `aiohttp.ServerTimeoutError` is both a `ClientError` and a `TimeoutError`; on Python 3.11 `asyncio.TimeoutError is TimeoutError`.
- The non-2xx body must be read while the response is still open (inside the `async with`).
- Ollama's embed fallback (`llm/ollama.py:332-334`) does `except LLMError` and checks for "status 404" in the text — DEC-001-7's message rule is what keeps transport failures out of that branch (DoD-10).
- The helper must not convert exceptions raised from the caller's block (DoD-9): map only around opening the request and the non-2xx check.
