# Step 001 — Package surface: load after install, version, factory credential, settings shape

## Goal

Make the package load after a normal install, align the version at 0.2.0, have the factory forward the app's credential to the OpenAI client, and let the typed settings shape describe every response-format value. Below the 50-line floor on purpose: its files are disjoint from every other step, so it runs in the first wave; merging it into step 004 would serialize it behind step 002.

## Source files

pyproject.toml
uv.lock
llm/__init__.py
llm/llm.py
llm/options.py

## Test files

tests/test_llm_factory.py
tests/test_package_surface.py

## Interface intent

- **Project metadata** (`pyproject.toml`): pydantic moves to the runtime dependencies (DEC-001-3); the version becomes 0.2.0 (DEC-001-4). The lock file is regenerated from it.
- **`__version__`** (`llm/__init__.py`): 0.2.0, equal to the project metadata version (DEC-001-4).
- **`get_llm_client`** (`llm/llm.py`): unchanged arguments and return; the `openai` branch now passes the caller's `bearer_token` to the OpenAI client like the other branches (DEC-001-5). The stale comment claiming the token is read from the environment is replaced.
- **`OpenAIOptions.response_format`** (`llm/options.py`): its value hint accepts nested JSON objects (a JSON-schema response format), not only string-to-string maps (DEC-001-14). No key is added or removed in any shape.

## Definition of done

1. [test] The project's declared runtime dependencies include pydantic, so a normal install brings everything the package imports at load (US-047.AC-1, DEC-001-3).
2. [manual/live] In a fresh environment with the package installed without the `dev` extra, `import llm` succeeds and `llm.pydantic_to_openai_tool` is importable (US-047.AC-1).
3. [test] `llm.__version__` equals the version declared in `pyproject.toml`, and both are `0.2.0` (DEC-001-4).
4. [test] `get_llm_client("openai", base_url, model, bearer_token=<t>)` returns an OpenAI client whose credential is `<t>` (US-003.AC-1, DEC-001-5).
5. [test] The factory still forwards the credential to llama-swap (and builds llama-swap without one), and still refuses an unknown server type with `ValueError` naming it (US-005.AC-1, US-002.AC-1).
6. [test] `tests/test_llm_factory.py` sets no process environment variable and builds every client with explicit arguments (DEC-001-5; tests folder convention).
7. [manual/live] `uv run ruff check llm/` is clean for the touched files.
