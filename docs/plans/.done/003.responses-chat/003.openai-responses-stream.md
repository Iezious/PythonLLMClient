# Step 003 — OpenAI Responses class: streamed chat, plus OpenAI live tests on both protocols

## Goal

Streamed `chat` and `generate` on `OpenAIAPIClient` read the Responses event stream: text and marked reasoning reach the receiver, a failure inside the stream or an early end raises the library error with the server's reason. Live tests check every non-tool chat operation on OpenAI on both protocols, and thinking on/off on Responses.

## Interface intent

- **Responses stream parser** (new private method on `OpenAIAPIClient`): inputs an open streamed response and an optional receiver; output the full text delivered (reasoning marked). Reads payloads only through `_iter_sse_data`; event handling, markers, completion and failures per DEC-003-13 (DEC-arch-11 minus tool events). Its own copy; nothing shared with the llama-swap class or the base (DEC-arch-2).
- **`chat`** (changed): the streamed path builds the body with step 002's payload builder (`stream` true), opens it through the base streamed-request helper on `/responses` (DEC-001-8, DEC-003-16), runs the parser inside the trace session with the trace wrapper only when tracing is enabled (DEC-000-48), logs and returns the text.
- **`generate`**: streamed generate goes through `chat`; no separate change beyond what `chat` provides.

## Definition of done

1. [test] A streamed `chat` opens one streamed request to `/responses` whose body equals the non-streamed body except `stream` is true (DEC-003-11, DEC-003-16).
2. [test] Output-text deltas reach the receiver as pieces in order, and the call returns their concatenation (US-008.AC-1, US-057.AC-1, DEC-003-13).
3. [test] Reasoning-summary deltas and reasoning-text deltas reach the receiver as reasoning: the first piece of a reasoning run starts with the opening marker, the first text piece after it starts with the closing marker; reasoning, text, reasoning, text gives two separate blocks; a block still open at completion is closed by a final closing-marker piece; the returned text equals everything the receiver got (US-059.AC-1, US-026.AC-1, US-026.AC-2, US-026.AC-4, DEC-000-20, DEC-003-13).
4. [test] A stream with no reasoning events gives no markers (US-026.AC-3).
5. [test] A failed event, an incomplete event and an error event each raise `LLMError` carrying the server's reason, and no piece after the event reaches the receiver (US-060.AC-2, DEC-arch-11, DEC-003-13).
6. [test] A stream that ends without the completed event raises `LLMError`, also when a `[DONE]` sentinel arrived; a stream ending with the completed event returns normally and anything after it is not delivered (US-024.AC-2, DEC-003-13).
7. [test] Unknown event types, non-JSON payloads, non-object payloads and empty deltas are skipped without error and without a receiver call (DEC-003-13).
8. [test] A streamed request that gets a non-2xx reply raises `LLMError` carrying the address and the server's reply and not the credential (US-060.AC-1, US-060.AC-4, DEC-arch-5).
9. [test] A receiver failure ends the call with that same exception and no later piece is delivered; an async receiver is awaited (US-022.AC-1, US-022.AC-2, DEC-000-23).
10. [test] A streamed `chat` without a receiver returns the full text; a streamed `generate` gives the same pieces as the equivalent one-message `chat` (US-021.AC-1, DEC-000-8).
11. [test] With tracing enabled, the receiver gets the same pieces and the call returns the same text as without tracing (US-050.AC-4, DEC-000-48).
12. [test] (live) On OpenAI with `OPENAI_MODEL`, on both protocols (Responses and chat completions, via the factory): `chat`, `generate` and `chat_json` return non-empty text, `chat_json`'s text parses as JSON, and a streamed `chat` returns exactly the text the receiver got; skipped without a key (US-057.AC-1, US-056.AC-1, US-056.AC-2, DEC-003-15).
13. [test] (live) On OpenAI Responses with `OPENAI_REASONING_MODEL`: a streamed chat with thinking on gives the receiver a well-formed reasoning block before the answer (US-059.AC-1, US-059.AC-2); with thinking off it succeeds with no reasoning block (US-059.AC-3, US-025.AC-5); thinking off with an explicit effort `low` succeeds (US-025.AC-4, DEC-003-1); a non-streamed chat with thinking on returns no marker (US-028.AC-1).
14. [test] (live) On OpenAI Responses with `OPENAI_NON_REASONING_MODEL`, thinking off ends with `LLMError` carrying the server's reason (DEC-003-1, US-060.AC-1).
15. [test] (live) On OpenAI Responses, an unknown model ends with `LLMError` carrying the server's reason and not the key, streamed and not; `list_models` on the Responses class returns a non-empty list of strings (US-060.AC-1, US-060.AC-4, US-057.AC-2).
