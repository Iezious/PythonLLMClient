## The shared request helper (read-only for this step)

`_request` is at `llm/llm_client.py:29-50`.

- A non-2xx reply raises `LLMError` (DEC-000-11). After feature 001, transport failures also raise `LLMError` (DEC-001-7).
- On a 2xx reply, it returns `await r.json()` when the Content-Type starts with `application/json`. That call can raise `json.JSONDecodeError` or `aiohttp.ContentTypeError`, uncaught. Otherwise it returns `await r.read()`, which is `bytes`.
- Catch only those two decode errors around the call. A broad `ValueError` catch is not allowed, because it could swallow unrelated errors.
